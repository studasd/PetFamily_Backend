# PetFamily Backend

Backend-сервис для волонтёрской платформы: размещение анкет животных, 
которых можно забрать/подарить новым хозяевам, ведение волонтёров и заявок.

## Стек
- .NET 10 / C#
- PostgreSQL + EF Core
- Docker / Docker Compose
- Чистая архитектура (разделение на слои, unit/integration тесты)

## Архитектура
Проект следует принципам чистой архитектуры с разделением на слои 
(Domain / Application / Infrastructure / API) — см. `src/`.
Тестовое покрытие ключевой бизнес-логики — см. `tests/`.

## Запуск
\`\`\`bash
docker-compose up -d
\`\`\`

## Ключевой функционал
- Создание и модерация анкет животных (фото, описание, статус: ищет дом / передан / на паузе)
- Профили волонтёров, ответственных за размещение и сопровождение анкет
- Заявки от потенциальных новых хозяев с историей статусов рассмотрения
